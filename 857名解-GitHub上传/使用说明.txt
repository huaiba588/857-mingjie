857 园林生态学 · 名解背诵 PWA
================================

一、手机直接使用（电脑需开着）
1. 手机和电脑连同一个 Wi-Fi。
2. 手机浏览器打开：http://192.168.3.10:8765/
   （如果电脑 IP 变了，以运行时显示的地址为准）
3. 先完整学习一张卡，确认进度能保存。
4. 添加到主屏幕：
   - iPhone Safari：分享 → 添加到主屏幕
   - Android Chrome：右上角菜单 → 添加到主屏幕 / 安装应用

二、电脑关掉也能用（离线单文件）
把“857名解-离线版.html”发到手机，用浏览器打开。
进度保存在该手机浏览器本地。
注意：换浏览器或清理浏览器数据，进度会丢；建议偶尔在“设置 → 导出学习数据”备份。

三、功能
- 每日新词 / 待复习
- 先自己回答，再显示答案
- 忘记 / 模糊 / 认识，按间隔复习
- 词库搜索、章节筛选、收藏、错词本
- 学习统计、连续打卡、章节进度
- 深色模式
- 设置里可导出 / 导入 JSON 进度
- 词库点开名词可“编辑答案”，保存成你自己的版本

四、数据说明
题库：857 园林生态学名词解释 169 个（重点 75 + 了解 94）（18 套模拟题 + 2019—2026 真题去重）。
答案：优先用已整理的 857 名解资料；新增/补充条目在答案下方标“补充说明”，表示不是原题手写答案。若与你的手写答案不一致，可在词库里点开该名词，点“编辑”改成你的版本。

五、部署成真正的 PWA（可选）
把本文件夹上传到任意 HTTPS 静态托管（GitHub Pages、Vercel、Netlify 等），
手机访问 HTTPS 地址后即可安装，并支持离线缓存。
